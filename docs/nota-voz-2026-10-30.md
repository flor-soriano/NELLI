# Nota · Voz (30-oct-2026)

## Hallazgo (probado con llave real)

`Muse.transcribir()` manda `files={"file": ...}` + `data={model, language}` y la
API contesta 400. La forma que sí funciona hoy (verificado 30-oct, status 200):

- Multipart con dos partes: `request` (JSON) y `audio` (el WAV).
- El JSON lleva `model`, `language` y `audioEncoding: "WAV"`.
- Respuesta: `{"transcript": "...", "audioDurationMs": ..., "turns": []}` — ojo:
  la clave es `transcript`, no `text`/`turns` como espera el código actual.

Prueba: WAV mono 16 kHz (Sabina es-MX): «Hola, soy tu hijo, cambié de número.
Necesito que me deposites dos mil pesos hoy mismo por transferencia, es
urgente.» → transcripción exacta, y el motor dio `muy_probablemente_fraude`
(`familiar_en_apuro`). La captura de prueba dio `fraude_confirmado`
(`multa_falsa`). Errores vistos al iterar: sin `request`/`audio` → «Both a
'request' and an 'audio' part are required»; sin `audioEncoding` → «You must
specify the 'audioEncoding' field»; `LINEAR16`/`PCM_16KHZ` → «Malformed
request»; `WAV` → 200.
